# WHAT IS STREAMLIT??

- open source python framework to create web applications
- it is a python UI library that allows to make web interfaces very quickly
- create frontends in python only
- create simple frontends fast and do the interaction with the applications
- useful for data science, ML and AI
- can also be deployed
- need python declarative code
- can work with numpy, pandas, matplotlib

### Streamlit functionality

- Normally Streamlit reruns the entire script(python file) whenever the user interacts with the page and changes the state of the application.
    - Without session_state, previous messages would disappear.
- streamlit supports hot reloading
    - if we change something in the python source code file and save, go to the streamlit website and refresh , it gets updated automatically
    - we do not have to rerun the file everytime we made some change.

- streamlit can be used for prototyping the applications
