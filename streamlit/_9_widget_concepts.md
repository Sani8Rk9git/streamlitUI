# Widget concepts

- Widgets are the elements that are holding some kind of state.
    - Ex: input box, button

- All the widgets are internally given a key(ID) which is autogenerated.
    - The IDs are given on the basis of type of element and the parameters that are given.
    - now if two same widget have the same parameters, then we cannot put them until we give ```key=""``` argument in one of the widget
